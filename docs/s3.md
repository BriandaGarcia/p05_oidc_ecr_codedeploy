# AWS Simple Storage Service (S3)

Se debe crear un bucket de S3 para almacenar los archivos que utilizará el agente de Code Deploy en el momento del despliegue en la instancia de EC2, para crear el bucket se utiliza el siguiente comando:


```bash
aws s3 mb s3://mi-app-codedeploy-NOMBRE-UNICO --region us-east-1
```
